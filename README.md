# Student Enrollment & Course Management System (SECMS)

## Project Description
A Salesforce-based application designed to manage student enrollment, courses, instructors, approvals, payments, and academic records.

## Technologies
- Salesforce
- Lightning App Builder
- Objects and Fields
- Flow Automation
- Data Validation
- Reports and Dashboards

## Project Objective
To streamline student enrollment and course management using Salesforce automation and data management features.
